Denslow's Three Bears

A demo of bookTranslate: Google Cloud Vision read the English words on each page of a slideshow, and Google Translate, through the Cloud Translation API, translated them into 8 languages; the results were saved (1-minute video). In desktop Chrome 138 or later you can also translate a page live, on your computer, with Chrome's built-in Translator API; the first time for each language, Chrome downloads a translation pack of up to about 85 MB. To translate your own books, run bookTranslate with your own Google Cloud project or key (how).

Export all pages (Excel)

The Excel file is what the scripts made from this slideshow (.pptx). Third-party parts and their terms are listed in THIRD_PARTY_NOTICES.md.

Denslow's Three Bears by W. W. Denslow, 1903, is in the public domain. Source: Project Gutenberg. Picture pages are the book's own pictures, some with the story lettered on them; the other pages were set in type from the book's text.
